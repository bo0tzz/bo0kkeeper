# Schema

Postgres tables. Authored as `@immich/sql-tools` decorator classes in `server/src/schema/tables/`; migrations generated by diff against the live DB.

## Money & dates

- All money stored as `bigint` **minor units** (cents) with explicit `currency` columns. Never `numeric` for money.
- All timestamps are `timestamptz`.
- Dates without a time-of-day are `date`.
- IDs are UUIDv7 (time-ordered, sortable, indexable).

## `events` — the spine

Append-only durable log of external events. Worker reads, marks processed in same tx as state-table writes.

| column | type | notes |
|---|---|---|
| `id` | `uuid` PK | UUIDv7 |
| `source` | enum | `wise`, `paperless`, `bank`, `manual`, `system` |
| `event_type` | text | namespaced: `wise.balances.credit`, `wise.transfer.state_change`, `paperless.document.consumed`, `bank.transaction`, `manual.invoice.issue`, ... |
| `external_id` | text | external system's idempotency key (Wise delivery UUID, paperless doc id, bank tx id, ...) |
| `occurred_at` | timestamptz | from external (`data.occurred_at` for Wise) |
| `received_at` | timestamptz | when we got it |
| `payload` | jsonb | full original body, verbatim |
| `status` | enum | `pending`, `processing`, `processed`, `failed`, `skipped` |
| `attempts` | int | retry counter |
| `last_error` | jsonb | nullable; message + stack + context when failed |
| `processed_at` | timestamptz | nullable |
| `correlation_id` | uuid | groups events for one logical flow (one Wise transfer's credit + state_changes share this) |
| `related_event_id` | uuid | nullable; one-step parent |

Indexes:

- `UNIQUE (source, external_id)` — idempotency: `INSERT ... ON CONFLICT DO NOTHING`
- `(status, received_at)` — worker scans pending
- `(event_type, occurred_at desc)` — replay/debug
- `(correlation_id)`
- GIN on `payload` — ad-hoc jsonb queries

## State tables

Written **only** by event handlers, in the same transaction that marks the event processed.
